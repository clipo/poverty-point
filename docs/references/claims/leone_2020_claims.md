# Claims: Leone 2020 (Poverty Point macrobotanical, Project 1/19)

**Full citation**: Leone, Karen L. 2020. *Macrobotanical Analysis, Project 1/19, Poverty Point (16WC5), West Carroll Parish, Louisiana*. Report prepared for the Poverty Point Station Archaeology Program (D. M. Greenlee), Poverty Point State Historic Site, Pioneer, Louisiana. (Samples from Project 1/19, near the dormitory; flotation-processed by Poverty Point personnel, analyzed June-August 2020.) Grey literature; no DOI. Source PDF: `docs/references/pdfs/16WC5_Project 1-19_Botanical Analysis.pdf` (has text layer).

## Claims
- **Assemblage:** 2,754 charred plant remains from 14 samples; categories include wood, cane, nuts, native cultigens, fruits, environmental seeds.
- **Early-summer cultigens:** maygrass (*Phalaris caroliniana*, n=9), amaranth (*Amaranthus* sp., n=7), little barley (*Hordeum pusillum*), chenopodium (*Chenopodium berlandieri*). "Maygrass is a starchy seed that ripens in late spring/early summer." Little barley "is an annual grass that thrives in disturbed habitats and ripens in early summer, thus providing a nutritious food source during a lean time of year and a storable seasonal complement to fall-ripening plant food resources."
- **Fall resources:** nuts (hickory/acorn) dominate; fall fruits (e.g., sumac, grape) present.
- **Note (NOT used in manuscript):** the report lists "cf. corn" (*Zea mays*, ~3.1%, uncertain ID). Corn would be anomalous/intrusive for the Late Archaic period; we deliberately do not cite Leone for corn.
- **Relevance:** the stronger of the two Leone reports for early-summer cultigens at the type site. Used in §1.2/§6.7/§7.4 to support the framework's multi-season (late-spring/summer + fall) prediction and to revise the older peripheral-site "spring dispersal / no spring plant evidence" inference (Thomas and Campbell 1978). Independent of the Webb/Jackson sources that define the phenology calendar, so it provides a partly non-circular seasonality check.
